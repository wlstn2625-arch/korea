# 🇰🇷 새로운 대한민국

> 내가 대한민국 대통령이 되어, **지금의 대한민국과 똑같은 제도**에서 출발해 헌법부터 민법·국방·외교·교육·세율·검경까지 하나씩 바꿔가며 새로운 대한민국을 만드는 정책 시뮬레이션 게임

## 실행 방법

설치할 것이 없습니다. 브라우저에서 바로 실행됩니다.

```bash
# 방법 1: 그냥 index.html 더블클릭
# 방법 2 (권장, Claude 연동 시 필요): 로컬 서버
python3 -m http.server 8000
# → http://localhost:8000 접속
```

## AI 판단 방식

1. **내장 AI 참모 (기본, 무료)** — `js/engine.js`의 규칙 기반 판단기. 현재 국가 상황(재정이 나쁘면 재정 지표의 가중치↑, 지지율이 낮으면 여론 가중치↑ 등)을 반영해 각 해법의 기대 효용 = 성공확률×성공 효과 + 실패확률×실패 효과 − 정치자본 비용을 계산하고, 선택 근거와 차선책 배제 이유를 설명합니다.
2. **Claude 연동 (선택)** — ⚙️ 설정에 Anthropic API 키를 넣으면 실제 Claude가
   - 위기 해법 선택(필요하면 목록에 없는 새로운 해법을 직접 설계),
   - 직접 입안한 정책의 효과 수치화,
   - 분기별 국정 논평과 정책 자문을 수행합니다.
   - 키는 브라우저 localStorage에만 저장되며 Anthropic API로만 전송됩니다. 사용량만큼 API 요금이 발생합니다. 호출 실패 시 내장 AI 참모로 자동 대체됩니다.

## 정책 추가하기

`js/data.js`의 `POLICIES` 배열에 항목을 추가하면 됩니다. 각 옵션의 `e`(지표 변화), `f`(세력 반응), `rel`(외교), `r`(부작용 리스크), `lt`(행정/법률/개헌), `pc`(정치자본), `lag`(효과 지연 분기)를 정의하세요.

> 게임 속 수치는 실제 제도와 연구를 참고한 **게임용 추정치**이며 실제 정책 효과를 예측하지 않습니다.
